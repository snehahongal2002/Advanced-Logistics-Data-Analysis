# Dataset description

`logistics_shipments.csv` is a simulated dataset created for an educational exercise. It does not contain real company or customer records.

## Rows and fields
- 200 shipments, one row per shipment.
- `Shipment_ID`: unique simulated shipment identifier.
- `Region`: North, South, East, or West.
- `Transport_Mode`: Road, Rail, or Air.
- `Distance_km`: route distance in kilometres.
- `Shipment_Volume_Units`: shipment volume in units.
- `Delivery_Time_Days`: simulated elapsed delivery time in days.
- `Transportation_Cost_INR`: simulated transport cost in Indian rupees.
- `Cost_per_Unit_INR`: transport cost divided by shipment volume.

## Limitations
Values are generated for demonstration, so conclusions are illustrative and should not be treated as evidence about a real logistics operation.
